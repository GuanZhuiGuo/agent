# 练习题与期末项目

> 每个模块都有自带练习（在该模块末尾）。本文件汇总**跨模块练习**和**期末项目**。

## 一、跨模块综合练习

### 练习 A · Agent 诊断报告

**目标**：用课程框架评估一个现有 Agent 产品。

**选择对象**（任选其一）：
- ChatGPT / Claude / Kimi（对话式）
- Cursor / GitHub Copilot / Claude Code（编程）
- Manus / Devin / ChatGPT Agent（长任务）
- 你自己公司的 Agent 产品

**交付物**（一份 2000 字左右的报告）：

1. **能力光谱定位**（模块 00）：它目前在哪一段？为什么？
2. **主循环拆解**（模块 01）：画一个它的 ReAct 循环图
3. **记忆诊断**（模块 02）：
   - 它记了什么？你怎么知道？
   - 哪些该记它没记？哪些记了但不该记？
4. **RAG 诊断**（模块 03）：
   - 它有没有 RAG？从哪些信号可以看出？
   - 它的"知道 / 不知道"边界在哪？
5. **工具 & 规划**（模块 04–05）：
   - 列出你观察到的至少 3 个工具
   - 规划模式判断
6. **Multi-Agent**（模块 06）：
   - 它是不是多 Agent？
   - 如果是，有何必要性？如果不是，你觉得要不要拆？
7. **评估与安全**（模块 07）：
   - 至少找 3 条"它翻车"的例子
   - 每条归因到管道哪一环
8. **优化建议**（模块 08）：列 5 条，按 ROI 排序

---

### 练习 B · 失败归因实战

**目标**：训练"看到差评 → 归因到管道"的能力。

**做法**：收集 10 条你产品（或你熟悉产品）的真实差评 / 错误 case。每条归入下面哪一类（可多选）：

- [ ] 上下文窗口塞不下 / 丢信息
- [ ] 记忆：该记没记
- [ ] 记忆：记了不该记
- [ ] RAG：切分不对
- [ ] RAG：检索不中
- [ ] RAG：Rerank 不足
- [ ] RAG：生成没有引用
- [ ] 工具：选错工具
- [ ] 工具：参数错
- [ ] 工具：死循环
- [ ] 规划：步数爆炸
- [ ] 规划：缺兜底
- [ ] Multi-Agent：错误级联
- [ ] Multi-Agent：共识幻觉
- [ ] 安全：越权 / 违规

**交付**：一张归因矩阵表 + 每个 case 的 1–2 句原因分析 + 修复建议。

---

### 练习 C · 成本杀手 Top 3

**目标**：建立 PM 成本直觉。

**做法**：
1. 按模块 08 · 8.3 的近似公式，估算你产品（或案例）的单任务成本
2. 把成本拆到步骤级：哪一步最贵？为什么？
3. 按模块 08 · 8.4 的 9 种手段，挑 3 种最适合你产品的，说明如何落地
4. 预估能降多少：___%

---

### 练习 D · 红队挑战赛

**目标**：在安全事故发生前，先模拟攻击自己。

**做法**：为你的产品写 **20 条**红队题，至少覆盖：
- Prompt Injection：5 条
- 诱导越权：4 条
- 诱导幻觉：4 条
- 敏感话题：3 条
- 异常输入：2 条
- 多语言 / 文化陷阱：2 条

**加分项**：实际跑一遍，标记通过 / 失败，写出整改方案。

## 二、期末项目

### 项目：为一个真实业务场景完整设计一个 Agent 产品

**场景选择**（挑一个，或你自选）：

1. **HR 面试筛选 Agent**：读简历 + 初面 + 给 HR 推荐
2. **合同审查 Agent**：读合同 + 风险提示 + 与模板对比
3. **电商导购 Agent**：理解需求 + 推荐商品 + 处理售前问题
4. **医疗预问诊 Agent**：问诊引导 + 结构化病史 + 交给医生（⚠️ 注意安全红线）
5. **财务分析 Agent**：读报表 + 指标解读 + 异常发现
6. **教育学习搭子 Agent**：学习进度跟踪 + 答疑 + 定制练习
7. **旅行规划 Agent**：收集偏好 + 查询 + 出行程 + 订票（⚠️ 高风险工具）
8. **研发运维 Agent**：值班答疑 + 告警诊断 + SOP 执行

---

### 必交付物

1. **Agent PRD**（用 `templates/agent-prd-template.md`）
2. **记忆画布**（用 `templates/memory-canvas.md`）
3. **评估记分卡 v0**（用 `templates/eval-scorecard.md`；可为"预估目标值"）
4. **20 条黄金题**（真实代表性）
5. **10 条红队题**
6. **一张系统架构图**（含所有组件与数据流）

### 加分项

- Multi-Agent 画布（如果你论证需要 Multi-Agent）
- 成本模型电子表格
- 与最接近的竞品的对比分析
- UX 原型或流程图
- 定价与商业模式

---

### 评分标准

| 项 | 权重 | 要点 |
|---|---|---|
| 问题定义清晰 | 10% | 用户故事、目标、Out of Scope 写得具体 |
| 能力光谱定位 & 规划选型合理 | 15% | 有**硬理由**，不是拍脑袋 |
| 记忆设计完整 | 15% | 分层、动作、治理、合规都覆盖 |
| RAG 设计有深度 | 15% | 每个决策点有选择与理由 |
| 工具清单与 HITL 档位合理 | 10% | 风险匹配 |
| Multi-Agent 决定有"反向论证" | 10% | 不是为拆而拆 |
| 评估 & 安全有落地路径 | 15% | 有黄金集、Rubric、红队、发布门槛 |
| 成本 / UX / 上线可执行 | 10% | 有数、有节奏 |

---

### 提交方式（建议）

- 一个文件夹：`my-project/` 包含所有交付物
- 一页 Summary，5 分钟内能讲清
- 同事 / 同学互评，收集 3 条批评意见

## 三、团队共学的 Workshop 建议

如果你是在团队内共学，用这些 workshop 让知识"落下去"：

| Workshop | 时长 | 产出 |
|---|---|---|
| "我们该不该做 Agent" 辩论 | 1h | 立项 Go/No-Go |
| 记忆画布共创 | 2h | 一份团队版记忆画布 |
| RAG 归因工作坊 | 2h | 现有产品的 20 条差评归因表 |
| Multi-Agent 反向论证 | 1h | 证明"我们不需要 Multi-Agent" |
| 红队比赛 | 2h | 50 条红队题 |
| 成本复盘 | 1h | Top 3 成本杀手 + 3 项优化 |
